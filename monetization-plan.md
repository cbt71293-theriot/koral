# Koral — Monetization Plan

> **Purpose:** Define how Koral generates sustainable revenue while keeping core capture and organization accessible.

---

## 1. Pricing Architecture

### 1.1 Tier Overview

| Tier | Price | Target | Primary Value |
|---|---|---|---|
| Free | $0 | Casual users, students, trial | Core notes, local storage, basic sync |
| Pro | $9.99/mo · $79/yr | Power users, writers, researchers | Advanced sync, AI assist, priority support |
| Team | $14.99/mo · $119/yr | Small teams, collaborators | Shared vaults, admin controls |
| Enterprise | Custom | Organizations, education | SSO, audit logs, dedicated support |

### 1.2 Free vs Paid Feature Gating

| Feature | Free | Pro | Team | Enterprise |
|---|---|---|---|---|
| Notes & links | Unlimited | Unlimited | Unlimited | Unlimited |
| Local storage | Unlimited | Unlimited | Unlimited | Unlimited |
| Theme system | System/Light/Dark | System/Light/Dark | System/Light/Dark | System/Light/Dark |
| Bi-directional links | ✅ | ✅ | ✅ | ✅ |
| Basic search | ✅ | ✅ | ✅ | ✅ |
| Semantic local search | — | ✅ | ✅ | ✅ |
| OneDrive sync | Basic | Advanced | Advanced | Advanced |
| E2EE sync | — | ✅ | ✅ | ✅ |
| Local AI assistant | — | ✅ | ✅ | ✅ |
| Shared vaults | — | — | ✅ | ✅ |
| Admin / roles | — | — | ✅ | ✅ |
| SSO / audit | — | — | — | ✅ |
| Priority support | — | ✅ | ✅ | ✅ |

---

## 2. Unit Economics

- CAC target: $18
- LTV target: $138
- LTV:CAC target: ≥7:1
- Break-even: ~540 paying users

---

## 3. Launch Timeline

| Phase | Users | Goal |
|---|---|---|
| Beta | 500 | Validate core flows, sync, search |
| Early Access | 5,000 | Conversion testing, pricing validation |
| Public Launch | 25,000+ | Scale content, partnerships, community |

---

## 4. Revenue Streams

- Subscriptions: primary revenue
- One-time exports/backups: optional add-on
- Team/Enterprise: higher-margin contracts
- No ads, no data selling
